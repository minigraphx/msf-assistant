## Task 1: Snapshot query layer
Implement src/msf_assistant/snapshot.py and tests/test_snapshot.py only. SnapshotReader(path: Path) with status(), profile(), roster(query: str='', offset: int=0, limit: int=50), inventory(query: str='', offset: int=0, limit: int=50), characters(query: str='', offset: int=0, limit: int=50), character(character_id: str). All return dict[str, Any]. SnapshotError is safe for client display.

Read file afresh per call (atomic sync replacements), validate JSON and shapes, sanitized errors without paths/contents. Data format: {profile:{data:{...},meta:{}},roster:{data:[{id,level,power,...}],meta:{}},inventory:{data:[{item,quantity}],meta:{}},retrieved_at:UTC ISO string,characters:[{id,name,...}] optional,characters_retrieved_at optional}. Existing live snapshot has 330 roster rows/1024 inventory rows, item may be string or object; support search on item ID/name recursively within item only. Do not read real secrets or include personal data fixtures.

Status reports availability/counts and retrieval times/age_seconds/stale (threshold24h). Missing snapshot status returns available false (other methods raise useful login/sync instruction); malformed file raises SnapshotError. Character absence reported clearly (sync --characters). Profile returns data plus retrieval metadata. Paged results return data,total,offset,limit,next_offset (None when done),retrieved_at,age_seconds,stale. limit 1..100 offset>=0; reject booleans/nonintegers. Query case-insensitive trimmed ID/name match; roster enrich display name from catalogue where present, sort descending numeric power, stable id ties. Don't mutate loaded raw API objects. Character by exact case-insensitive ID returns static data + matching roster row (or None) with separate timestamps, or safe not found error. Timestamp must be valid timezone-aware, reject nonfinite JSON. No network or keychain access. Tests first, then implementation, run targeted pytest/Ruff. Report work/mcp-query-report.md; no commits while root edits other files.
